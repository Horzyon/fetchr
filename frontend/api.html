Grab ← Retour

API

Trois endpoints. Un token. Intègre Grab dans tes scripts, bots, ou apps.

https://api.grab.download/v1
Authentification

Ajoute ton token dans le header de chaque requête :

Authorization: Bearer grab_sk_xxxxxxxxxxxx

Génère ton token dans les paramètres de ton compte.

Limites
50
requêtes/jour (Free)
1000
requêtes/jour (Pro)
Endpoints
POST /prepare
Lance le pré-fetch d'une vidéo. Retourne les métadonnées et un session_id.
Requête
POST /v1/prepare { "url": "https://youtube.com/watch?v=dQw4w9WgXcQ" }
Réponse
{ "session_id": "a1b2c3d4", "title": "Rick Astley - Never Gonna Give You Up", "thumbnail": "https://i.ytimg.com/vi/.../maxresdefault.jpg", "duration": "3:33", "views": 1786000000 }
GET /status/{session_id}
Vérifie si le pré-fetch est terminé. Poll jusqu'à ce que les deux soient true.
Réponse
{ "video_ready": true, "audio_ready": true }
POST /download
Télécharge le fichier converti. Retourne un stream binaire (le fichier).
Requête
POST /v1/download { "session_id": "a1b2c3d4", "format": "video", "quality": "1080p" }
ParamTypeDescription
session_idrequis string ID retourné par /prepare
formatrequis string "video" ou "audio"
qualityrequis string 4k, 1080p, 720p, 480p, flac, mp3_320, mp3_128, m4a_128
Exemple complet
# 1. Prépare la vidéo SESSION=$(curl -s -X POST https://api.grab.download/v1/prepare \ -H "Authorization: Bearer grab_sk_xxxx" \ -H "Content-Type: application/json" \ -d '{"url": "https://youtube.com/watch?v=dQw4w9WgXcQ"}' \ | jq -r .session_id) # 2. Attends que ce soit prêt while ! curl -s https://api.grab.download/v1/status/$SESSION | jq -e '.video_ready' > /dev/null; do sleep 2 done # 3. Télécharge curl -s -X POST https://api.grab.download/v1/download \ -H "Authorization: Bearer grab_sk_xxxx" \ -H "Content-Type: application/json" \ -d "{\"session_id\": \"$SESSION\", \"format\": \"video\", \"quality\": \"1080p\"}" \ -o video.mp4
