Endpoints
POST /prepare
Lance le pre-fetch d'une video. Retourne les metadonnees et un session_id.
Requete
POST /v1/prepare { "url": "https://youtube.com/watch?v=dQw4w9WgXcQ" }
Reponse
{ "session_id": "a1b2c3d4", "title": "Rick Astley - Never Gonna Give You Up", "thumbnail": "https://i.ytimg.com/vi/.../maxresdefault.jpg", "duration": "3:33", "views": 1786000000 }
GET /status/{session_id}
Verifie si le pre-fetch est termine. Poll jusqu'a ce que les deux soient true.
Reponse
{ "video_ready": true, "audio_ready": true }
POST /download
Telecharge le fichier converti. Retourne un stream binaire (le fichier).
Requete
POST /v1/download { "session_id": "a1b2c3d4", "format": "video", "quality": "1080p" }
ParamTypeDescription
session_idrequis string ID retourne par /prepare
formatrequis string "video" ou "audio"
qualityrequis string 4k, 1080p, 720p, 480p, flac, mp3_320, mp3_128, m4a_128
Exemple complet
# 1. Prepare la video SESSION=$(curl -s -X POST https://api.fetchr.fr/v1/prepare \ -H "Authorization: Bearer fetchr_sk_xxxx" \ -H "Content-Type: application/json" \ -d '{"url": "https://youtube.com/watch?v=dQw4w9WgXcQ"}' \ | jq -r .session_id) # 2. Attends que ce soit pret while ! curl -s https://api.fetchr.fr/v1/status/$SESSION | jq -e '.video_ready' > /dev/null; do sleep 2 done # 3. Telecharge curl -s -X POST https://api.fetchr.fr/v1/download \ -H "Authorization: Bearer fetchr_sk_xxxx" \ -H "Content-Type: application/json" \ -d "{\"session_id\": \"$SESSION\", \"format\": \"video\", \"quality\": \"1080p\"}" \ -o video.mp4

Wait while (true) { const status = await fetch(`${API}/status/${session_id}`).then(r => r.json()); if (status.video_ready && status.audio_ready) break; await new Promise(r => setTimeout(r, 2000)); } // 3. Download const blob = await fetch(`${API}/download`, { method: "POST", headers, body: JSON.stringify({ session_id, format: "video", quality: "1080p" }) }).then(r => r.blob());
